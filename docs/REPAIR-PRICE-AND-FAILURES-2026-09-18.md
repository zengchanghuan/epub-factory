## 调价规则

- 新建非 AI 格式转换/繁简/排版优化订单：默认 **1.99 元/本**，批量按文件数计算。
- 独立 EPUB 格式修复新订单：默认 **0.99 元/本**。
- AI 翻译仍按原字符计费及 5.99 元最低价；润色阶梯计费不变。
- 历史订单保留原 `expected_amount`，独立修复旧单保留保存的冻结报价和支付金额；回调按下单金额校验，不能以新价格改写历史报价或放行金额不符的付款。
- 此前生产只读检查发现 `CONVERSION_PRICE_CNY=5.99`，不能只改代码默认值。部署迁移将转换配置的未设置/空值或精确旧值 `5.99` 改为 `1.99`，将独立修复配置的未设置/空值、精确旧值 `5.99` 或先前默认值 `1.99` 改为 `0.99`，保留其他自定义价格、管理员测试价与翻译价格。
- 本文记录本地实现与回归；是否上线以实际执行部署后的验证为准。

独立修复新订单的报价/付款金额和状态保存到原文件目录的 `order.json`，重复发起支付、回调及进程重启均按冻结金额核对。已确认付款的本地修复可通过显式 `POST /recover` 或 `POST /pay` 恢复；只读状态 GET 不调度任务，同一 API 进程防止重复线程，成品完整写入后原子替换。升级前仅有内存状态、从未保存元数据的独立修复订单无法自动迁移；默认 `/tmp` 目录也不保证系统清理后保留。这些限制已记入部署说明，不影响数据库中的历史转换订单金额。
