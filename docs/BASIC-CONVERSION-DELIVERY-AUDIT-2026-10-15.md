# 基础繁简转换与付款交付回归（2026-10-15）

本轮审查覆盖普通 EPUB 繁简转换、转换降级、付款校验、持久化投递、失败恢复和文件领取。历史订单、原稿及既有成品只读；验收在服务器私有临时目录使用独立数据库，不发布测试订单，不调用真实支付或模型服务。案例仅以 A/B 表示，不记录客户姓名、订单号、领取凭据或原稿路径。

## 发现与修复

| 严重程度 | 原行为与风险 | 修复 |
| --- | --- | --- |
| P1 | 核心繁简转换器处理章节抛错，被当作可跳过的清洗错误；未转换正文仍可能打包成功 | 必需的繁简转换失败立即终止，不进入降级交付；保留取消和 worker 超时的控制流 |
| P1 | 普通转换只有 EPUB 格式校验，合法的 EPUB 仍可能少正文或空段落 | 清洗前建立正文结构清单，EPUBCheck 通过后核对章节和文本单元；不完整结果不可交付 |
| P2 | 降级复用已经修改的书，可能沿用损坏正文；还会恢复默认词典配置、遗漏目录标题转换 | 从原稿重新解包，保留繁简方向、地域版本、词典开关及专名设置，同样转换目录并执行交付门禁 |
| P2 | 选中的词典缺失、为空、依赖不可用或初始化异常时静默禁用 | 明确报告转换失败，不把不符合所选配置的成品当作成功 |

正文清单兼容纯图片书：不强迫其存在正文，但仍检查原有文档存在。已有翻译任务默认仍要求非空正文清单。此门禁检测缺失/空文本单元，不声称能够识别非空段落内的一切删字或语义错误；真实样本另做逐文档规范化正文哈希、阅读顺序及二进制资源核对。
