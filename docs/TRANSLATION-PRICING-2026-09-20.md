## 决策

标准 DeepSeek Flash 翻译从 ¥0.10/千字符、最低 ¥5.99，调整为：

| 计费区间 | 标准 Flash 单价 |
| --- | ---: |
| 最低价 | ¥3.99 |
| 前 30 万字符 | ¥0.05/千字符 |
| 30-100 万字符的超出部分 | ¥0.035/千字符 |
| 100 万字符以上的超出部分 | ¥0.025/千字符 |

高质量模式乘 1.5，文学模式乘 2；选择 `deepseek-v4-pro` 时再乘 3.4。固定价 `TRANSLATION_PRICE_CNY` 仍是运维显式覆盖，不自动套用倍率。没有设置硬性低封顶，避免超大文集因固定封顶倒挂。

## 依据与边界

- 生产环境默认使用 DeepSeek 官方 `deepseek-flash`，没有备用供应商；旧别名仍由官方路由至 V4.1 Flash。
- 2026-09-20 核对的官方 Flash 高峰价为输入未命中 ¥2/百万 Token、输出 ¥8/百万 Token，空闲价减半；Pro 输出价约为 Flash 的 3.375 倍。
- 近期一笔成功标准翻译报价 ¥72.71，旧统计记录 317,358 输入与 816,090 输出 Token。按全部高峰价估算主翻译调用约 ¥7.16；该旧统计可能遗漏画像、术语、审校和异常请求，不能冒充供应商实际账单。
- 26 个非测试翻译报价的中位数为 ¥74.41；18 个超过 ¥50，其中 16 个未越过付款门槛；6 个超过 ¥100 的报价均未越过付款门槛。样本量有限，不能单独证明因果，但足以支持灰度降价。

完整逐请求账本部署后，应以实际账单继续观察模型成本、支付成功率、失败重试和退款。价格评估不得把未知费用当作 0 元。

官方依据：[DeepSeek 模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)。
