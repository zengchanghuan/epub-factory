# PDF 接入方案入口

2026-10-02 用户最新范围：**PDF 本阶段只处理可靠文本层；图片保持原样，不做像素 OCR、图片文字翻译或重绘。** 扫描正文识别及图像处理保留为后续 TODO。原 MinerU/Flash 全能力方案是历史设计，不是本期开发或调用外部服务的授权。
