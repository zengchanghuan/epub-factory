## 数据和能力边界

- `extract_pdf_text_ir` 是纯本地诊断入口，输出 `pdf-text-ir-v1`，绑定原稿SHA和pypdf版本。每页恰好一次；页/资源ID包含schema版本、原稿SHA及稳定遍历序号，片段ID继承页ID。原始`object_id`另存用于去重和溯源；不同对象不能只凭相同字节合并。
- 页 `raw_text` 保留原解析文字，包括零宽字符；`fragments` 保留visitor回调次序与变换信息，**不是已经识别的段落或可靠阅读顺序**。嵌套Form、复杂变换或片段拼合不一致显式标待复核，不能伪造成功。
- 图片保存的是**解密后、过滤器解码前的编码stream**及其SHA和来源对象。对当前真实书是DCT/JPEG压缩数据；不是PDF文件中的加密ciphertext，也不重新编码成另一张JPEG/PNG。
- B1资源标志始终含 `encoded_stream_only`。当前没有完整重建ColorSpace/ICC、Decode、Mask/SMask、裁切与绘制位置，不能宣称IR中的单个stream已经是可独立正确显示的完整图片。后续资源重建仍须逐项对照原PDF渲染。
- 未支持的过滤器按不透明数据保留并要求复核；不能可靠处理的inline image、Pattern、Type3字形、注释外观AP、ExtGState软遮罩与Form外部引用则明确拒绝，不能漏记其内部图片后继续成功。图片对象本身的SMask只标记依赖，不宣称已重建。源页原件和图片保持不变，不进行OCR。
- 元数据和目录仅当作不可信源数据保存，不读取其中的路径/URL，不执行脚本。CLI默认不输出标题、作者、正文或图片base64；显式报告先写同目录0600临时文件并flush/fsync，再以no-clobber硬链接发布，中断清理私有临时文件，绝不覆盖旧文件。私有报告不能当作公开诊断日志上传。
- 所有结果固定 `review_required`、`eligible_for_payment=false`；公共PDF入口仍关闭，未发生真实付款、模型调用、部署或生产清理。

## 本地命令

```bash
# 默认只有统计，不返回正文。
backend/.venv/bin/python scripts/inspect-text-pdf-ir.py /absolute/path/selected-book.pdf

# 显式请求才保存私有结构数据；目录由操作者准备，文件必须不存在。
backend/.venv/bin/python scripts/inspect-text-pdf-ir.py /absolute/path/selected-book.pdf \
  --report /private/tmp/new-private-pdf-ir.json
```

默认工程上限：文件50MiB、500页、60秒、每页100万字符、总1000万字符、每页2万/全书20万片段、1万独立图像资源、单资源20MiB/总编码资源32MiB/JSON64MiB。它们尚未成为产品承诺或覆盖所有PDF的安全保证。macOS内存限制不可用须明确显示；生产Linux资源隔离另行验收。
