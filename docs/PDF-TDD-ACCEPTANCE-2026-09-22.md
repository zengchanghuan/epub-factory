## 实现与发现

- **逐页提取并发**：`PDF_OCR_CONCURRENCY=2`，允许 1–4。小批次调度限制内存与在途请求，保持页码顺序；传递 ContextVar，使 OCR 请求正确归属订单/尝试/阶段。主机总并发还受 Celery worker 数量影响，不能把每任务上限当作全主机限流。
- **错误与落盘**：余额、鉴权、取消、结果不明等错误阻止后续批次及分片请求；已发出的请求等待完成并保存。单页内容待核验可继续其他页。共享请求计数及单页请求均用文件锁保护，覆盖线程和共享磁盘上的进程，避免并发覆盖预算或同页重复计费。
- **段落重组**：Flash 根据明确的 `layout=paragraph` / 相邻 `paragraph_id` 组装正文，保存原文字和来源块序号；代码、公式、诗行、列表和未知换行不擅自合并。跨物理页、不同识别裁剪区域不猜测拼接，连字符不擅自删除。
- **原生文字布局**：PDFium 根据坐标、字号与字体拆分标题、正文和代码。单栏正文只在行距、边界等证据满足时连接换行，保留原行与行号。等宽字体必须另有代码语法证据，防止把打字机小说当代码而跳过翻译。提取文字不一致或布局异常转 OCR；不自动重做既有任务或旧缓存。
- **资源稳定性**：同步术语处理使用自有、会关闭的事件循环，避免每本书残留循环；调用方已有运行中的循环继续沿用，不擅自关闭。

真实样本暴露了此前小型模拟用例没有覆盖的问题：文本 PDF 整页和 Python 示例原先合成一个巨型段落，一段反复触发内联标签校验失败。新增原生布局回归后修复，保护代码示例并缩小翻译单元。扫描样本旧 OCR 按印刷行拆分，曾导致比较关系译文遗漏；本次在隔离目录显式重新识别 4 页，采用新段落契约后修正。生产缓存不会因为提示词更新而自动再次收费。

## TDD 与离线证据

新增用例文件：

- `backend/test_d39_pdf_concurrency_reflow.py`：并发上限、实际重叠、顺序、会计上下文、原子预算、取消、致命错误等待同批成功页落盘、保守重组。
- `backend/test_d40_pdf_translation_acceptance.py`：真实预处理、生产翻译器、回写、EPUBCheck、最终交付审计；替身仅用于外部接口。独立核对请求数、输入/输出 Token 和精确十进制费用，检查原页图片字节、代码/公式、页码锚点和全部指定译文。
- `backend/test_d41_pdf_fault_soak.py`：同页 40 次并发只请求一次、真实 SDK 响应解析与线程记账、坏 JSON 仍计费、事件循环关闭、1,000 轮随机完成顺序下的故障/恢复。
- `backend/test_d42_pdf_native_layout.py`：代码、标题、段落分离及等宽正文防误判。

先运行缺失功能测试看到失败，再实现；串行链路的并发屏障测试先超时，接入并发后通过；原生布局缺失和等宽正文误判也分别先复现再修复。

中断验证包括两种真实子进程强制结束：

1. 翻译段落检查点写入后 `SIGKILL`，删除普通译文缓存，再启动新进程；已完成段落从持久化检查点恢复，没有重复接口请求，最终 EPUB 可交付。
2. OCR 请求已记为在途、结果尚未收到时 `SIGKILL`；重启保持“结果待核实”，不盲目再发请求。此场景不冒充可以无条件自动恢复。

这些故障注入没有调用付费模型。1,000 轮测试约 8 秒，验证重复执行和故障边界，**不是连续数天的生产稳定性证明**。

沿用此前公开样本（作者公开 Python 教材、公共领域微积分扫描件），两份各 6 页。源文件仍按物理页码对照输出，不是版面保持型译文 PDF。

|---|---:|---:|
| 页数 | 6 | 6 |
| 最终失败段落 | 0 | 0 |
| EPUBCheck / 最终交付检查 | 通过 | 通过 |
| 原页图片字节 / 页码锚点 | 保留 | 保留 |
| 代码与独立公式块 | 11 块与提取源完全一致 | 无独立保护块；原页保留 |
| 本轮累计模型请求（含前次失败/修复） | 29 | 50 |
| 本轮累计计费估算（CNY） | 0.18110200 | 0.11390168 |
| 未知 usage / 待核实计费请求 | 0 | 0 |
| 禁用接口后的完整重跑 | 0 新请求，约 4 秒 | 0 新请求，约 4 秒 |

扫描样本的 50 次请求含 4 次新 OCR，其余是术语、书名、正文及补译；2 页 MinerU 结果沿用此前有效缓存。新 OCR 两路并发 4 页耗时 **5.38 秒**；这是小样本观测，未做同时间同页面串行对照，不承诺所有书都能等比例加速。重新提取后的正式翻译约 9.64 秒，但复用了已有术语、书名和部分段落，不能作为冷启动整书速度。

本轮总计 **79 请求、0.29500368 元估算成本**，含失败与重新验收，低于预设新增 1 元预算。此前接口比较实验约 0.151694 元单列，不重复计入本轮；两轮实验合计约 0.44669768 元。费用依据实际逐请求 usage 和现有留存价目计算，**不是供应商对账单**，也不是最终一次成功转换的标准成本。没有请求量归零后丢失旧费用的情况。

两份最终译文、逐请求账本、预算、原始响应和检查报告位于私有目录 `artifacts/repair-regression-pdf-acceptance-20260922/formal-translation/`。文件 `translated-01.epub`、`translated-02.epub` 是本轮最终产物。均仍有 3 个非阻断复核提示，涉及术语、数字表示和句子规则；修复比较关系遗漏并抽查，不等同于逐句人工审校、整书质量或 Apple Books/Kindle 的全部阅读体验验收。

## 可重复运行

```bash
  test_d37_pdf_pipeline test_d37_pdf_providers test_d37_pdf_api \
  test_d38_pdf_acceptance_fixes test_d39_pdf_concurrency_reflow \
  test_d40_pdf_translation_acceptance test_d41_pdf_fault_soak \
  test_d42_pdf_native_layout test_d29_translation_performance \
  test_d31_llm_usage_ledger -q

  python -m unittest test_d41_pdf_fault_soak -q

# 有权限的本机私有语料与已保存响应；禁止网络，不重新付费
python scripts/regress-pdf-corpus.py \
  --corpus-root artifacts/repair-regression-pdf-acceptance-20260922 \
  --output-dir artifacts/repair-regression-pdf-acceptance-20260922/offline-replay
```
